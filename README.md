GoodsAccounting
База данных для учета товаров, категорий и поставщиков
О проекте
Данный проект представляет собой базу данных для автоматизации учета товаров, поставщиков и поставок. Разработан в рамках выполнения технического задания по администрированию и оптимизации баз данных.

Структура базы данных
Таблицы
Таблица	Назначение
Categories	Хранение категорий товаров (Электроника, Одежда, Продукты и т.д.)
Suppliers	Информация о поставщиках (название, контакты, ИНН)
Products	Товары (код, название, цены, остатки, привязка к категориям и поставщикам)
Deliveries	Поставки (номер, дата, статус, общая сумма)
DeliveryDetails	Детали поставок (какие товары, в каком количестве и по какой цене)
AuditLog	Журнал изменений (автоматически записывает все изменения в таблицах)
Представления (Views)
Представление	Описание
vw_ProductDetails	Детальная информация о товарах (с названиями категорий и поставщиков)
vw_DeliveryDetails	Информация о поставках с подсчетом количества позиций
vw_CategoryStatistics	Статистика по категориям (количество товаров, общая стоимость)
vw_LowStockProducts	Товары с низким остатком (ниже минимального)
vw_AuditLog	Журнал изменений с сортировкой по дате
Хранимые процедуры
Процедура	Назначение
sp_AddProduct	Добавление нового товара с проверкой уникальности кода
sp_RegisterDelivery	Регистрация новой поставки (принимает JSON с товарами)
sp_ConfirmDelivery	Подтверждение поставки и автоматическое обновление остатков
sp_SearchProducts	Поиск товаров с фильтрацией по разным параметрам
Триггеры
Триггер	Назначение
trg_Products_UpdateModified	Автоматически обновляет дату изменения товара
trg_Products_CheckMinQuantity	Предупреждает при достижении минимального остатка
trg_DeliveryDetails_UpdateTotal	Автоматически пересчитывает общую сумму поставки
trg_Suppliers_PreventDelete	Защищает от удаления поставщиков с привязанными товарами
Индексы
Для оптимизации производительности созданы индексы:

IX_Products_ProductName (поиск по названию)

IX_Products_CategoryID (связь с категориями)

IX_Products_SupplierID (связь с поставщиками)

IX_Deliveries_DeliveryDate (поиск по датам)

IX_Deliveries_Status (фильтрация по статусу)

Роли и права доступа
Созданные роли:
Роль	Права	Для кого
db_Manager	Полный доступ (SELECT, INSERT, UPDATE, DELETE)	Администраторы
db_Operator	Добавление и редактирование, но без удаления	Сотрудники склада
db_Analyst	Только чтение данных	Аналитики, отчетность
Примеры пользователей:
Manager_User (полный доступ)

Operator_User (ограниченный доступ)

Analyst_User (только чтение)

Резервное копирование
Скрипты:
08_Backup_Script.sql - полное резервное копирование

09_Restore_Script.sql - восстановление из резервной копии

Инструкция по развертыванию
Способ 1: Выполнение скриптов по порядку
Открыть SQL Server Management Studio

Подключиться к серверу (например, localhost\SQLEXPRESS)

Выполнить файлы в следующем порядке:

№	Файл	Назначение
1	01_Create_Database.sql	Создание базы данных
2	02_Create_Tables.sql	Создание таблиц
3	03_Create_Indexes.sql	Создание индексов
4	04_Create_Views.sql	Создание представлений
5	05_Create_StoredProcedures.sql	Создание хранимых процедур
6	06_Create_Triggers.sql	Создание триггеров
7	07_Create_Roles_Permissions.sql	Настройка ролей и прав
8	08_Backup_Script.sql	Скрипт резервного копирования
9	09_Restore_Script.sql	Скрипт восстановления
10	10_Test_Queries.sql	Тестовые запросы
11	11_Performance_Analysis.sql	Анализ производительности
